# V11 多机器人正式实验数据说明

本目录是论文 **Experiment II（多机器人数量零成本迁移实验）** 的精简数据包。
仅保留最终 V11 正式评估、冻结模型、训练配置、论文统计图和一个独立采集的场景级
轨迹样例。旧模型诊断、3 回合短测、V12--V16 调试实验、训练日志、Unity 缓存与构建
文件均未上传。

论文中的 Experiment I 是单智能体 RL 与 ARL 对照实验，本轮没有复现，因此不在本
数据包中。请勿使用本目录的数据替代或证明 Experiment I 的结果。

本目录中的实验数据、派生统计、元数据和轨迹记录采用
[CC BY 4.0](LICENSE) 许可；目录外的项目源代码采用仓库根目录中的 MIT License。

## 正式测试条件

- 机器人数量：1--5；策略训练时的基准数量为 3。
- 机器人模型：`models/RobotBrain-59962.pt`，测试时完全冻结且不重新训练。
- 人类模型：`models/HumanBehavior_1.29_1.onnx`，测试时启用并冻结。
- 独立基础种子：204101、204201、204301。
- 每个机器人数量、每个种子运行 100 回合，共 1,500 回合。
- 每回合 50 名人类，最长 150 s，`time_scale=20`。
- 使用 Python ML-Agents 确定性推理和固定测试布局。
- `panic_state=-1` 表示由人类策略输出行为状态，不是把所有人固定成某一种 panic 状态。
- `use_fire=False` 表示没有生成显式火焰对象；CO 和温度相关数值仍保留在人类观测/
  环境数据链路中。本版 Experiment II 的可见度接口没有进入实际控制链路。
- 测试的是“冻结机器人策略 + 固定辅助控制器”。搜索、协调搜索、送达、跟随保持和
  恢复辅助均开启，出口吸附关闭。论文中应据此表述为组合控制器的零成本数量迁移，
  不应夸大为完全涌现、完全无规则辅助的协作。

## 最终结果

下表的“均值 +/- 标准差”均在三个 seed-level 结果之间计算，不是把 300 个回合直接
视为独立样本得到的标准误。

| 机器人数量 | 逃生率 (%) | 最终健康得分 | 每回合死亡人数 |
|---:|---:|---:|---:|
| 1 | 30.78 +/- 1.96 | 60.59 +/- 0.85 | 5.52 +/- 0.28 |
| 2 | 38.89 +/- 0.81 | 67.38 +/- 0.12 | 4.12 +/- 0.32 |
| 3 | 44.50 +/- 1.06 | 72.28 +/- 0.82 | 2.52 +/- 0.15 |
| 4 | 50.82 +/- 2.37 | 73.83 +/- 0.93 | 2.02 +/- 0.12 |
| 5 | 53.96 +/- 0.98 | 75.63 +/- 0.69 | 1.80 +/- 0.15 |

指标定义：

- `SuccessRate = 100 x 逃生总人数 / 初始总人数`。
- `AvgEscapedHealthAll = 逃生者健康值总和 / 初始总人数`。它不是“仅对成功逃生者
  取平均后的健康值”，而是按初始人群归一化的综合得分。
- `AvgFinalHealthAll = 逃生者与截止时仍存活者的健康值总和 / 初始总人数`。
- 聚合表中的误差线是 3 个种子的样本标准差；95% CI 使用 Student t 分布，
  `n=3`、`df=2`、`t=4.302652729`。
- `timeout` 表示回合正常运行到 150 s 上限，不表示 Unity 或 ML-Agents 闪退。

## 文件用途

- `formal_evaluation/aggregate.csv`：论文表格和柱状图对应的三种子聚合结果。
- `formal_evaluation/seed_results.csv`：15 个正式批次各自的最终结果。
- `formal_evaluation/episodes/`：15 个原始 CSV，每个文件恰好 100 个回合。
- `formal_evaluation/summaries/`：运行中每 10 回合累计一次的汇总，使用
  `IsFinal=true` 的最后一行作为正式结果。
- `formal_evaluation/metadata/`：每个正式批次的实际运行参数，便于核验没有混入其他
  模型或辅助参数。
- `formal_evaluation/figures/`：正式 1--5 机器人指标图的 PDF 和 PNG。
- `trajectory_example/`：3 机器人、seed 204195 的单回合轨迹记录和场景时间线图。
- `configs/`：V11 POCA 训练配置。
- `models/`：正式评估所用的机器人 checkpoint 和冻结人类 ONNX。
- `LICENSE`：实验数据采用的 CC BY 4.0 许可说明。
- `DATA_DICTIONARY.md`：全部 CSV 字段定义。
- `MANIFEST.csv` 与 `checksums/SHA256SUMS.txt`：文件清单和完整性校验值。

轨迹样例不属于正式 `3 seeds x 100 episodes` 统计批次，只用于解释机器人空间覆盖、
引导链形成和人群状态随时间的变化，不能当作额外统计证据。

## 校验方法

在仓库根目录运行：

```powershell
conda run -n EvacARL python experiment_data/verify_dataset.py
```

脚本会检查 15 个正式文件和 1,500 条回合记录，重新计算 seed-level 与 aggregate
结果，检查关键测试参数、轨迹文件和 SHA-256。平台相关的 Unity 可执行文件体积较大，
本次数据发布没有上传；复算论文 Experiment II 的表格、误差线和指标不依赖该构建文件。
